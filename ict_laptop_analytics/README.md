🚀 အဓိက လုပ်ဆောင်ချက်များနှင့် ကျွမ်းကျင်မှုများ (Key Features & Skills)
Web Scraping & Data Extraction: Selenium နှင့် undetected-chromedriver တို့ကို အသုံးပြု၍ Dynamic ဝဘ်ဆိုဒ်များမှ Page အလိုက် (Pagination) Laptop အချက်အလက်များကို အလိုအလျောက် ဆွဲထုတ်ခြင်း။

Data Cleaning & Formatting: Pandas ကို အသုံးပြု၍ ကွဲပြားနေသော ဈေးနှုန်းစာသားများကို ဂဏန်းဒေတာအဖြစ် ပြောင်းလဲခြင်း၊ မလိုချင်သော characters များနှင့် spaces များကို သန့်စင်ခြင်း။

Data Analysis & Reporting: အမြင့်ဆုံး၊ အနိမ့်ဆုံးနှင့် ပျမ်းမျှ ဈေးနှုန်းများကို တွက်ချက်ပြီး Statistical Report ထုတ်ပေးကာ CSV ဖိုင်အဖြစ် သိမ်းဆည်းခြင်း။

Task Automation: လူကိုယ်တိုင် အချိန်ကုန်ခံ ရှာဖွေစရာမလိုဘဲ Script တစ်ခုတည်းဖြင့် Routine အလုပ်များကို အလိုအလျောက် (Auto) လုပ်ဆောင်နိုင်ခြင်း။

🇬🇧 English Version
An end-to-end data automation project built with Python to scrape e-commerce laptop data, clean and format the dataset, and generate comprehensive price analytics reports.

🚀 Key Features & Skills Demonstrated
Web Scraping & Data Extraction: Automated data extraction from dynamic e-commerce web pages using Selenium and undetected-chromedriver with pagination support.

Data Cleaning & Formatting: Processed raw strings into structured numerical data using Pandas, removing currency symbols ('K'), commas, and handling whitespace/duplicates.

Data Analysis & Reporting: Calculated key statistical insights including highest, lowest, and average prices, exporting clean analytical reports to CSV format.

Task Automation: Designed automated script workflows to streamline repetitive data collection and processing tasks.

🛠️ Tech Stack
Language: Python

Libraries: Selenium, Undetected-Chromedriver, Pandas
